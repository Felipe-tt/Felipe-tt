### 👋 About me

</div>

I'm a **Junior FullStack Developer** based in Blumenau, SC — Brazil, currently working at **Lince Tech**.

I started my journey in technical support, learning how systems behave from the user's perspective. Over time, I moved into development — and that background still shapes the way I write code today.

On the back-end I work with **Java**, developing and maintaining web systems, handling business rules, and reviewing code. I use **SQL Server** daily for queries, updates, and query optimization. On the front-end I build interfaces with **JavaScript, jQuery, AJAX, JSON, HTML and CSS**. I manage tasks with **Jira**.

I also have experience with process automation using **N8N** and **WhatsApp bots** with Botpress and BotConversa.
